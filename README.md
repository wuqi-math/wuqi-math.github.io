# qiwumath 个人主页

直接打开 `index.html` 可在本地预览。主页使用 HTML 和 CSS，无需安装依赖。

## 发布到 GitHub Pages

1. 登录 `wuqi-math`，在 GitHub 创建公开仓库 `wuqi-math.github.io`。
2. 将本目录内的文件放到仓库根目录，确保 `index.html` 位于 `main` 分支的根目录。
3. 打开仓库的 **Settings → Pages**。在 **Source** 选择 **Deploy from a branch**，选中 **main** 和 **/(root)**，点击 **Save**。
4. 部署成功后，打开 [wuqi-math.github.io](https://wuqi-math.github.io/)。[GitHub Pages 官方快速入门](https://docs.github.com/en/pages/quickstart)

## 更新内容

在 `index.html` 中编辑 `research`、`publications`、`notes` 和 `contact` 四个区块。论文可在 `publications` 中按年份加入题名、作者、期刊和 DOI 链接。`styles.css` 管理配色和布局。星空封面为本主页生成，文件名为 `starfield.jpg`。
